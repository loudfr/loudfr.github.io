Aperçu du projet

Description du projet

Développement d'une application mobile multiplateforme utilisant Flutter et Dart. L'application propose une interface moderne et intuitive avec des fonctionnalités avancées de gestion de données, synchronisation cloud et expérience utilisateur optimisée.

Ce projet m'a permis de découvrir le développement mobile moderne et de maîtriser les spécificités du framework Flutter, reconnu pour sa performance et sa capacité à créer des applications natives pour iOS et Android à partir d'une seule base de code.

Technologies utilisées

Flutter Dart Firebase SQLite REST API Git

Fonctionnalités développées

  • Interface utilisateur responsive et moderne
  • Authentification et gestion des comptes utilisateurs
  • Synchronisation des données avec Firebase
  • Stockage local avec SQLite pour le mode hors-ligne
  • Intégration d'APIs externes
  • Notifications push
  • Navigation intuitive et animations fluides
  • Support multilingue

Défis techniques rencontrés

  • Flutter : Apprentissage du framework et de ses widgets
  • État : Gestion complexe de l'état de l'application
  • Responsive : Adaptation à différentes tailles d'écran
  • Performance : Optimisation pour les appareils moins puissants
  • Asynchrone : Gestion des appels API et de la synchronisation

Compétences développées

Développement mobile

Flutter, Dart, widgets, navigation

Backend as a Service

Firebase, authentification, base de données

UX/UI Mobile

Design patterns, Material Design

Architecture

MVVM, gestion d'état, clean code

Apprentissages sur le mobile

Ce projet m'a sensibilisé aux spécificités du développement mobile : contraintes de performance, gestion de la batterie, adaptation aux différentes tailles d'écran, et importance de l'expérience utilisateur tactile. J'ai également découvert l'écosystème Flutter et ses avantages pour le développement multiplateforme.
