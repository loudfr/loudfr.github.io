Aperçu du projet

Description du projet

Développement d'un site web complet pour l'association sportive "Rapidos" spécialisée dans la course à pied. Le projet incluait la création d'une identité visuelle, la conception et le développement du site web avec des fonctionnalités de gestion des membres, des événements et des performances.

Ce projet SAE (Situation d'Apprentissage et d'Évaluation) nous a permis de mettre en pratique l'ensemble du cycle de développement web, de l'analyse des besoins à la livraison du produit final.

Technologies utilisées

HTML5 CSS3 PHP Java MySQL Git

Fonctionnalités développées

  • Page d'accueil avec présentation de l'association
  • Système d'inscription et de connexion des membres
  • Gestion des événements et compétitions
  • Suivi des performances individuelles
  • Interface d'administration
  • Design responsive pour mobile et desktop

Défis rencontrés

  • Gestion de projet : Organisation du travail en équipe avec Trello et respect des délais
  • Design : Création d'une identité visuelle cohérente et attractive
  • Technique : Intégration PHP/MySQL pour la gestion des données
  • Responsive : Adaptation du design pour tous les appareils

Compétences développées

Développement Web

HTML, CSS, PHP, intégration front/back-end

Base de données

Conception et utilisation de MySQL

Gestion de projet

Planning, organisation, travail en équipe

Design

Création d'identité visuelle, UX/UI
