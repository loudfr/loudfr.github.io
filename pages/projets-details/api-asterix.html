Aperçu du projet

Description du projet

Développement d'une API REST complète avec Node.js et Express, thématisée autour de l'univers d'Astérix. L'API permet de gérer une base de données de personnages, villages gaulois et aventures, avec toutes les opérations CRUD (Create, Read, Update, Delete) et une documentation Swagger intégrée.

Ce projet m'a permis d'approfondir mes connaissances en développement backend, architecture REST, et bonnes pratiques de développement d'APIs modernes avec authentification et validation des données.

Technologies utilisées

Node.js Express MongoDB Mongoose JWT Swagger Postman

Fonctionnalités développées

  • API REST complète avec toutes les méthodes HTTP
  • Base de données MongoDB avec Mongoose
  • Système d'authentification JWT
  • Validation des données d'entrée
  • Gestion des erreurs et codes de statut HTTP
  • Documentation automatique avec Swagger
  • Tests d'endpoints avec Postman
  • Middleware de sécurité et CORS

Endpoints principaux

  • GET /personnages - Liste tous les personnages
  • POST /personnages - Crée un nouveau personnage
  • PUT /personnages/:id - Met à jour un personnage
  • DELETE /personnages/:id - Supprime un personnage
  • GET /villages - Gestion des villages gaulois
  • POST /auth/login - Authentification utilisateur

Défis techniques rencontrés

  • Architecture : Structuration propre du code en modules
  • Base de données : Modélisation efficace avec MongoDB
  • Sécurité : Implémentation JWT et validation des données
  • Documentation : Création d'une doc Swagger complète
  • Tests : Validation de tous les cas d'usage

Compétences développées

Backend Node.js

Express, middleware, routing

Base de données NoSQL

MongoDB, Mongoose, modélisation

Architecture REST

Bonnes pratiques, codes HTTP, CRUD

Sécurité API

JWT, authentification, validation

Documentation et tests

Une attention particulière a été portée à la documentation de l'API avec Swagger UI, permettant aux développeurs de tester directement les endpoints. Des collections Postman complètes ont également été créées pour faciliter les tests et l'intégration.
