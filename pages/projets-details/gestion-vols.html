Aperçu du projet

Description du projet

Application Java avec interface graphique Swing permettant de gérer une base de données de vols aériens. L'application offre des fonctionnalités de recherche, de filtrage et d'affichage des vols disponibles selon différents critères (ville de départ, ville d'arrivée, dates, compagnies).

Ce projet m'a permis d'approfondir mes connaissances en programmation Java, en conception d'interfaces utilisateur et en intégration de bases de données MySQL dans une application desktop.

Technologies utilisées

Java MySQL JDBC

Fonctionnalités développées

  • Interface graphique intuitive avec Swing
  • Connexion et requêtes à une base de données MySQL
  • Recherche de vols par ville de départ et d'arrivée
  • Filtres avancés
  • Affichage des résultats en tableau
  • Gestion des erreurs et validation des données

Défis techniques rencontrés

  • Base de données : Conception du schéma et optimisation des requêtes SQL
  • JDBC : Gestion des connexions et des transactions
  • Performance : Optimisation des requêtes pour de gros volumes de données
  • Ergonomie : Conception d'une expérience utilisateur fluide
